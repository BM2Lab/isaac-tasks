# panda assets

`libero_scene.py` stages the pinned native LIBERO Object-0 Panda/room/objects
from a validated native export. No binary meshes or USDs are committed here;
conversion is explicit and requires an existing isolated native asset cache.

Joint/TCP conventions, metadata, verification and known PhysX approximations
are documented in `docs/p1_libero_scene.md` at the repository root. This is not
the historical FR3 model or the generic reach/config/panda placeholder.
